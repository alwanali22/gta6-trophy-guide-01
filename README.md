Sunset Platinum is the best offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in its own words that cites its sources (Exophase and PSNProfiles), a checklist whose progress is saved in the browser with export and import, filters by kind and grade, a spoiler setting that hides story trophies until they are earned, a five-stage roadmap to the platinum, a missables watch list built from the official descriptions, and a smart Next-up planner. It is a static web app with no build step and no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` from any static file server with `app/` at its root.
