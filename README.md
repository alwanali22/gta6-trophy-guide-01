Sunset Platinum — an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5: all 55 official trophies (1 platinum, 2 gold, 6 silver, 46 bronze) with guides written in our own words from the official descriptions, a 5-stage roadmap to the platinum, a missables page where every flag shows its basis in the official description, per-trophy count counters, notes, a smart Next-up planner, search and filters, a spoiler guard that hides story trophies until earned, and progress saved in the browser with export/import. No network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
